# Claude Max 购买：没有海外信用卡时的付款路径、5x 与 20x 差价及代订阅风险清单

Claude Max 的价格是公开的。Anthropic 官方帮助中心写得很清楚：网页订阅，Max 5x 每月 100 美元，Max 20x 每月 200 美元，目前只有月付，没有年付选项。信息一点都不难找。

难的是点开付款页面之后那一步。国内用户在这里遇到的是卡被拒、账单地址对不上、账号所处地区不在支持名单里这一类问题，和 Claude 本身好不好用没关系。

这篇不讲模型评测，只处理一件事：在国内把 Claude Max 买下来并且稳定用下去，有哪几条路，各自要花多少钱，哪些环节最容易翻车。

## 先把官方价格和限制看准

除了价格，官方帮助中心还固定了几条规则，买东西之前值得先知道：

- Max 5x 提供 Pro 每会话 5 倍的用量，Max 20x 是 20 倍
- 两档都有更高的输出上限、高峰期优先访问，以及新功能和新模型的优先体验
- **Max 目前只提供月度订阅**，没有年付
- 从 Pro 年付升级到 Max，剩余余额会以账户 credit 的形式保留，前提是账单地址与之前一致；地址变了就得先取消再等结束
- 官方明确表示不提供常规折扣价，Max 5x 和 20x 都不例外，只偶尔有限时活动

所以如果你看到"Claude Max 官方折扣""年付省 30%"这类说法，基本可以直接划走。

### 5x 和 20x 差的不是"5 倍和 20 倍"这么简单

Max 的两档同时受两层限制：5 小时滚动窗口限制单次会话能烧多少，另有一条跨模型的每周总额度。两道闸门独立运行，哪个先到就先卡住。

这不是说 Max 不值，而是说**选档位时别只盯着"20 倍"这三个字**。你一天大概跑多久 Claude Code、每周撞几次限额，比倍数本身更能决定该买哪档。

## 国内购买 Claude Max 的三个卡点

**支付**：国内银行发行的 Visa/Mastercard 在 Anthropic 侧被拒是常态，虚拟卡刚开通能用、过一阵又失效的情况也不少。

**地区**：Claude 官方服务的支持地区名单里没有中国大陆，这是最先撞上的墙。

**环境**：注册和使用时的网络环境会被风控判定。数据中心 IP（VPS、机场节点的常见属性）通过率很低，DNS 泄露、时区语言与 IP 地区不匹配同样会被识别。

三个卡点叠在一起，就催生了国内各种"代订阅"服务。WildAI（BeWild.ai）是其中被讨论得比较多的一个。

## 买 5x 还是 20x

判断依据就一条：你每周会不会撞限额。

如果你主要是写文档、读长文、偶尔让它写点脚本，Pro 通常够用，5x 是给每天高频使用的人准备的。真正需要 20x 的是那些把 Claude Code 挂在终端里跑一整天、同时开好几个 agent 干活的人——这类用法烧额度非常快，撞到周额度之后，要么等重置，要么按 API 价额外买用量。

Anthropic 官方允许 Pro 和 Max 用户打开 usage credits，超额部分按标准 API 价计费，有月度上限和自动充值设置。也就是说**买了 Max 不等于不会再花钱**，这条对重度用户尤其重要。

从 5x 升 20x 按账单周期剩余时间比例计费，不用等到期。所以拿不准的话，先上 5x，一个月后看用量再决定，比一开始就砸 200 美元稳妥。

## 用代订阅平台之前，把这四件事弄清楚

**Session 凭据不等于密码，但它确实是登录凭证。** 插件读取的是你浏览 Claude 时的登录状态，代付方不需要你的密码，但持有 Session 的一方在理论上具备访问对应账号的能力。平台方声称不会用这个方式登录用户账号，这句话的可信度只能靠自己评估。用完订单之后，在 Claude 侧主动登出并重新登录，可以刷新掉旧的会话状态。

**网络环境决定成不成功。** 住宅 IP、DNS 与出口 IP 一致、浏览器指纹与 IP 地区匹配，这三项是平台的硬性检测项，不是建议。只有机房 IP 的话，失败概率明显更高。

**续费可能出问题。** 有用户记录过 BeWild 的具体故障：一个三个月套餐没按期自动续费，另一笔新买的两月套餐订单显示完成但账号仍是免费版，最后两笔分别拿到了退款处理或退款方案。平台会处理，但中间的空档期是你自己在承当。

**封号后的退款规则值得提前问清楚。** 论坛里有用户描述过规则是"官方退款则平台按约 71.5% 退、另扣约 3.3 美元服务费，官方不退款则平台不负责"。这是用户转述，不是官方条款，下单前建议自己跟客服确认一遍并留下聊天记录。

## 哪些人适合走这条路，哪些人不适合

适合的：没有海外信用卡，也不打算为了一个订阅去开卡、充 USDT、研究账单地址；已经有自己的 Claude 账号，不想换成来路不明的共享号；能接受每月多花十美元左右买省事。

不适合的：手上有稳定可用的海外卡且支付一直顺畅，那直接去官方订阅更干净，还省掉一层中间人；只是偶尔用 Claude 的人，免费版和 Pro 之间的差距没那么大；还有一类是准备两个人拼一个 20x 的——论坛里"闲鱼 Claude Max 20x 拼车，一天就封"这种帖子不是孤例。
